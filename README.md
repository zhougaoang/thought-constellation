# 思想星图 · thought-constellation

<p align="center">
  <img src="assets/icon-180.png" width="120" alt="思想星图图标">
</p>

把零散的思想片段，编织成一张会生长的星图。

你写下「商业认知」「人生规划」这样的主题，然后一段一段往里放想法（键盘输入，想到什么写什么）。点一次「开始分析」，模型会把全部片段读成一个整体，抽出**核心命题、主题、观点、观点之间的关系、以及还没想清楚的问题**，画成一张深空星图，并在右侧写下一份总结：论证链、张力与矛盾、盲点、下一步。

再放新的想法进去，重新分析，星图会同时包含新旧观点——你能直接看到自己的思考在哪里长出了新枝，在哪里自相矛盾。

## 它做什么

- **按项目组织思考**：左侧项目栏可新建、重命名、删除（删除需二次确认），每个项目是一个独立主题。
- **片段式录入**：每次输入只追加一段，不会覆盖之前的原文；原文档案里可以看到每一段，也能删掉某一段再重新分析。
- **手动触发分析**：上传只负责存下来，点「开始分析」才会调用模型，避免每次输入都消耗一次调用。
- **分层星图**：核心命题居中，主题在内环，观点在中环，待补充的问题在外环；关系用五种颜色的弧线表示（支持 / 因果 / 对立 / 递进 / 例证）。
- **可回溯原文**：每个观点上的角标是它引用的原文条数，点开右侧抽屉能看到逐字引用和上下文，还能跳到相关观点。
- **AI 总结**：核心命题、论证链、张力与矛盾、盲点、下一步，五段结构。
- **可收起的侧栏**：项目栏和总结栏都能收起成一条竖把手，状态记在浏览器里。
- **分析过程可见**：分析时旧图压暗，顶部依次显示「读取片段 → 提取观点 → 建立关系 → 撰写总结」。

## 安装

需要 DeepSeek Harness Web 或 Desktop（0.2.x），并且已经配置好至少一个模型。

从插件市场安装，或在终端：

```sh
dsh plugin add thought-constellation
```

从本地目录安装（开发时）：

```sh
dsh plugin add /path/to/thought-constellation
```

安装后在左侧栏点星座图标打开工作台。

## 数据存在哪

全部在本机，一个项目一个 JSON 文件：

```
~/Documents/思想工坊/
  index.json          项目列表与摘要
  proj_<id>.json      该项目的全部原文片段 + 最近一次分析结果
```

Windows 上是 `C:\Users\<你>\Documents\思想工坊`。删掉文件就等于删掉项目；备份直接拷这个文件夹。

## 隐私

原文和分析结果只写在本机。点「开始分析」时，片段内容会通过 DSH 发送给你当前选中的模型提供商——用的是宿主已经配好的模型，插件本身不存任何 API Key、不访问其他网络地址。

## 已知限制（第一版）

- 不做语音输入（后续版本）
- 不做导出长图、历史版本对比、单点追问、多端同步
- 单次分析适合约 3 万字以内；超出时会先把较早的片段压成要点再分析
- 模型输出必须是合法 JSON；格式不对会自动修复重试一次，仍失败则保留旧图并给出错误条

## 开发

```
index.js      Host 半：本地 JSON 存储、LLM 调用、HTTP 路由（/thought-constellation/api/*）
client.js     Client 半：侧边栏图标 + main 面板，纯 React.createElement，SVG 星图
locale/       中英文案
icon.svg      侧边栏与插件页图标
assets/       市场卡片图标
```

Host 半通过 `webServer` 注册 `kind: 'exact'` 路由，客户端用同源 `fetch` 调它；请求先过 `sameOrigin` 与连接准入检查。
